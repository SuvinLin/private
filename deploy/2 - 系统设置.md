**本设置依赖 macOS Catalina（10.15.3 ）**



### 先运行几个 mac tips.md 中的命令

[mac tips.md](../tools/mac tips.md)



#### 菜单栏设置

​	电池图标 → 显示百分比



#### Finder 偏好设置

- 通用 → 在桌面上显示这些项目 → 只选外置磁盘

- 边栏 → 个人收藏 → 勾选（隔空、应用程序、桌面、文稿、下载、用户）

​						iCloud 勾选

​						位置	→  勾选（硬盘、外置磁盘、已连接的服务器）

- 高级 → 除了（将以下位置的文件夹保持在顶部的两个选项不勾选，其余全选）



### 桌面文件夹设置

- 桌面 → 查看显示选项 → 图标大小（56 * 56）→ 网格间距（滑块位置与图标大小位置保持一致）
- 桌面 → 排序方式 → 贴紧网格



### 系统偏好设置

#### Apple ID

-  iCloud → 仅勾选下列选项
  - iCloud云盘 → 选项（系统偏好设置）
  - 钥匙串
  - 查找我的 Mac
- 媒体与购买项目 → 免费下载 → 始终不需要



#### 通用

​	最近使用的项目 → 选择 0



#### 桌面与屏幕保护程序

- 安装并选择  Brooklyn.saver 
- 开始前闲置 → 永不 
- 触发角 → 将左上角设为启动屏幕保护程序



#### 程序坞

​	只有（在程序坞中显示最近使用的应用程序）不选，其余选项全选



#### 辅助功能 

​	指针控制 → 鼠标与触控板 → 触控板选项 → 启动拖移（三指拖移）



#### 安全性与隐私 

​	防火墙 → 打开



#### 软件更新

- 自动保持我的 Mac 最新（取消）
- 高级 → 检查更新（取消）



#### 网络 

​	为当前连接的网络添加 DNS 8.8.8.8



#### 蓝牙

​	关闭



#### 键盘

- 键盘 → 全部取消勾选
- 快捷键 → 聚焦 → 全部取消
- 快捷键 → 输入法 → 设置 选择上一个输入法（command space）



#### 触控板

​	所有选项开启

​	

#### 节能

- 电池 → 此时间段后关闭显示器（拉到最右）
- 电源适配器 → 此时间段后关闭显示器（拉到最右）

 

#### 日期与时间

​	时钟 → 在菜单栏中显示日期和时间（取消勾选）
