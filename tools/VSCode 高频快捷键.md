command + k + l	折叠/展开所在行代码块

command + k + 0	折叠所有代码块

command + k + [	展开最外层代码

command + alt + up/down	移动光标，使之选择多行

command + shift + [ / ]	或者	command + alt + left / right	左右切换编辑器

command + shift + k	清除整行

ommand + b  隐藏侧边栏

command + shift + x   打开扩展页面

command + shift + e	打开资源管理器

command + ctrl + shift + right	选择范围内代码，在次使用会扩大选择区域

command + ctrl + shift + left	缩小选择范围内代码，在次使用会缩小选择区域

command + k  and command + s	显示快捷键



alt + shift + f	格式化代码

alt + z 切换自动换行

alt + shift + i 	在所选的每一行的末尾插入光标



ctrl + g	快速定位到行
